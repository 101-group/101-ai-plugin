Для бизнеса

Данные и действия без переключения между экранами

Плагин подходит владельцам бизнеса, руководителям, финансистам, бухгалтерам, менеджерам проектов и командам, которые ведут работу в 101.

ChatGPT удобен для бизнес-диалога, анализа и повседневных операций. Codex дополняет эти возможности работой с кодом, файлами, тестами и репозиториями.

Безопасность

Доступ только в рамках прав пользователя

Репозиторий не содержит паролей, токенов, API-ключей или пользовательских данных. Подключение выполняется через OAuth, а удалённый сервер 101 MCP проверяет права перед выполнением операций.
