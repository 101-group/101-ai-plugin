# Public 101 Plugin 2.0.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить публичный Codex-плагин `101` версии `2.0.6`, который устанавливается без приватного приложения, подключает production MCP напрямую, предлагает Google Drive и Notion как необязательные приложения и безопасно направляет пользователя на пополнение AI-токенов.

**Architecture:** Marketplace `101 Marketplace` устанавливает skills 101, remote MCP `https://app.101-group.ru/mcp` и две optional app dependencies. PDF и Sales остаются отдельными OpenAI-плагинами: `101-index` описывает границы совместной маршрутизации, но не копирует их skills или app manifests.

**Tech Stack:** JSON manifests Codex, Markdown skills, Python `unittest`, ZIP release artifact, Codex plugin CLI.

**Spec:** `docs/superpowers/specs/2026-08-23-public-101-plugin-design.md`

## Global Constraints

- Plugin, display name и MCP server key: `101`.
- Marketplace name: `101-marketplace`; display name: `101 Marketplace`.
- Release version: `2.0.6` без cachebuster в Git.
- MCP URL и OAuth resource: `https://app.101-group.ru/mcp`.
- Google Drive: `connector_5f3c8c41a1e54ad7a76272c89e2554fa`, `required: false`.
- Notion: `asdk_app_69c18c28f1188191bf5b8445c4ab0a2e`, `required: false`.
- Не добавлять `101-private`, `101-v2`, приватный `asdk_app_6a8a2c8be2088191b622c8c0fd50d4e8`, PDF или Sales в runtime app manifest.
- Не копировать PDF skill, proprietary Sales skills или 27 app dependencies Sales.
- В backend менять только MCP-контракт `insufficient_tokens`; immutable analytics widget bundle не менять.
