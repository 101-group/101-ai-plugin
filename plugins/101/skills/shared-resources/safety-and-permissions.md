# Безопасность и права

- API является единственным источником прав, видимости данных и бизнес-валидации. Инструкции скилла не расширяют доступ.
- MCP централизованно задаёт OAuth scopes, признаки риска и обязательное подтверждение. Не вводи параллельное подтверждение и не обходи штатное.
- Безопасное чтение можно ограниченно повторить после временной ошибки. Запись нельзя повторять без доказанной идемпотентности или подтверждения, что первый вызов не выполнился.
- При неопределённом исходе записи верни `частично` или `заблокировано`, сохрани квитанции и сначала проверь серверное состояние.
- Обязательная недоступная зависимость блокирует только затронутый сценарий. Не заменяй отсутствующие данные предположениями.
- Обычный итог содержит статус `готово`, `частично` или `заблокировано`, результат, проверенные или изменённые данные, свежий post-write результат и минимальный следующий шаг.
