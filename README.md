# 101 AI Plugin — плагин 101 для ChatGPT, Codex и MCP

**101** — приложение для финансового учёта и управления бизнесом. Оно объединяет проекты, деньги, взаиморасчёты, CRM, сметы, события, отчёты, Wiki и файлы. Плагин 101 позволяет работать с этими возможностями через искусственный интеллект в ChatGPT и Codex.

Репозиторий содержит готовые навыки 101 и прямое подключение к публичному production MCP. Навыки задают проверенные рабочие сценарии, а MCP предоставляет инструменты, интерактивные виджеты и доступ к актуальным данным с учётом прав пользователя.

## Возможности

- анализ финансового состояния компании и проектов;
- работа с поступлениями, расходами, платежами и взаиморасчётами;
- управление проектами, участниками и финансовыми показателями;
- работа с CRM, воронками, этапами и сделками;
- создание и обновление смет, отчётов и связанных позиций;
- диалоговый разовый импорт данных в текущую компанию владельцем компании;
- работа с событиями, сроками и позициями проектов;
- интерактивная деталка задачи со сменой статуса и исполнителя, комментариями и файлами;
- чтение и обновление Wiki, документов и файлов;
- отображение интерактивной аналитики и графиков прямо в интерфейсе AI-ассистента.

## Кому подходит

Плагин предназначен для владельцев бизнеса, руководителей, финансистов, бухгалтеров, менеджеров проектов и команд, которые ведут работу в 101 и хотят обращаться к данным и рабочим процессам на естественном языке.

**Codex** предназначен для локальной работы на компьютере: с кодом, файлами, тестами, GitHub и GitLab. **ChatGPT** удобен для бизнес-диалога, аналитики, отчётов и повседневных операций; после подключения 101 им можно пользоваться как на компьютере, так и в мобильном приложении ChatGPT.

## Установка через 101 Marketplace

Плагин устанавливается через **101 Marketplace** в ChatGPT:

1. Откройте **Настройки → Плагины**.
2. Нажмите **Добавить → Добавить маркетплейс**.
3. В поле **Источник** вставьте:

   ```text
   https://github.com/101-group/101-ai-plugin.git
   ```

4. В поле **Git ref** укажите `main`.
5. Поле **Выборочные пути** оставьте пустым и нажмите **Добавить маркетплейс**.
6. Вернитесь в **Настройки → Плагины → Магазин** и нажмите **Просмотреть каталог**.
7. Найдите в каталоге плагин **101**, откройте его карточку и нажмите **Установить**.
8. Откройте новую задачу и обратитесь к данным 101.
9. При первом использовании пройдите авторизацию в 101 через OAuth и вернитесь в Codex.

После подключения ChatGPT должен показать плагин **101** версии `2.2.1` и MCP-сервер с названием **101**.

**После установки откройте новую задачу (новый чат) в Codex.** Уже открытые задачи не подхватывают новые навыки и MCP-инструменты.

## Как устроен плагин

Плагин состоит из двух основных частей:

1. **Навыки 101** — инструкции и рабочие процессы для AI-ассистента.
2. **101 MCP** — удалённое приложение, которое предоставляет инструменты, данные и интерактивные виджеты.

Данные компании не хранятся в этом репозитории. Пользователь подключает собственную учётную запись 101 через OAuth, после чего сервер проверяет его права перед выполнением операций.

Разовый импорт доступен только владельцу текущей компании. Простой CSV обрабатывается напрямую; для сложного Excel или другой сложной таблицы используется отдельно установленный **Spreadsheets**. Его инструкции и assets не копируются в пакет 101.

Необязательные Google Drive и Notion объявлены как отдельные приложения. PDF и Sales не входят в пакет 101: навыки только задают безопасные границы совместной маршрутизации, чтобы сопутствующий плагин не мог заблокировать установку 101.

## Совместимость с Claude

Текущий пакет использует формат маркетплейса Codex и манифест `.codex-plugin`. Этот Git-репозиторий можно использовать как общий источник для разных AI-агентов, но Claude требуется собственный поддерживаемый манифест и отдельный способ установки. Не считайте текущий пакет напрямую совместимым с Claude, пока соответствующий слой совместимости не будет добавлен и протестирован.

## Возможные проблемы и решения

| Проблема | Решение |
| --- | --- |
| Плагин установлен, но не появляется в текущем чате | Создайте новую задачу (новый чат) в Codex. Уже открытые задачи не подхватывают новые навыки и MCP-инструменты. |
| Установлена старая версия плагина | Откройте **Настройки → Плагины → Магазин**, обновите маркетплейс **101 Marketplace**, затем обновите плагин **101**, если Codex предлагает обновление. Актуальная версия указана в разделе «Версия» ниже. |
| В Codex установлено несколько плагинов с названием 101 | Оставьте актуальный жёлтый плагин **101** версии `2.2.1` из маркетплейса **101 Marketplace**, а старые и дублирующие версии удалите или отключите, чтобы они не конфликтовали. |
| Не появляется OAuth или инструменты 101 | Во вкладке **Плагины** убедитесь, что **101** включён, откройте новую задачу и повторите первый запрос к данным 101. |
| Не подключён Google Drive или Notion | Основная работа 101 доступна. Подключите нужное приложение отдельно только для сценария, которому требуются его данные. |
| Недоступен PDF или Sales | Включите соответствующий отдельный плагин Codex. Установка и инструменты 101 от него не зависят. |
| MCP сообщает «Недостаточно AI-токенов» | Плагин откроет переданную сервером страницу пополнения во встроенном браузере или покажет кликабельную ссылку. До пополнения исходный платный вызов не повторяется; бесплатные инструменты остаются доступны. |
| После обновления и нового чата плагин всё равно не работает | Полностью закройте и заново запустите Codex, затем создайте ещё одну новую задачу. |

## Безопасность

Репозиторий не содержит паролей, токенов, API-ключей, закрытых ключей или пользовательских сессий. Авторизация и права доступа к данным проверяются удалённым сервером 101 MCP через OAuth. Никогда не добавляйте в репозиторий секреты или локальные данные авторизации.
