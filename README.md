# 101 AI Plugin — плагин 101 для ChatGPT, Codex и MCP

**101** — приложение для финансового учёта и управления бизнесом. Оно объединяет проекты, деньги, взаиморасчёты, CRM, сметы, события, отчёты, Wiki и файлы. Плагин 101 позволяет работать с этими возможностями через искусственный интеллект в ChatGPT и Codex.

Репозиторий содержит готовые навыки 101 и подключение к зарегистрированному приложению 101 MCP. Навыки задают проверенные рабочие сценарии, а MCP предоставляет инструменты, интерактивные виджеты и доступ к актуальным данным с учётом прав пользователя.

## Возможности

- анализ финансового состояния компании и проектов;
- работа с поступлениями, расходами, платежами и взаиморасчётами;
- управление проектами, участниками и финансовыми показателями;
- работа с CRM, воронками, этапами и сделками;
- создание и обновление смет, отчётов и связанных позиций;
- работа с событиями, сроками и позициями проектов;
- чтение и обновление Wiki, документов и файлов;
- отображение интерактивной аналитики и графиков прямо в интерфейсе AI-ассистента.

## Кому подходит

Плагин предназначен для владельцев бизнеса, руководителей, финансистов, бухгалтеров, менеджеров проектов и команд, которые ведут работу в 101 и хотят обращаться к данным и рабочим процессам на естественном языке.

ChatGPT удобен для бизнес-диалога, аналитики, отчётов и повседневных операций. Codex дополняет эти возможности работой с кодом, локальными файлами, тестами, GitHub и GitLab.

## Установка

### 1. Установка в Codex

1. Откройте **Настройки → Плагины**.
2. Нажмите **Добавить → Добавить маркетплейс**.
3. В поле **Источник** вставьте:

   ```text
   https://github.com/101-group/101-ai-plugin.git
   ```

4. В поле **Git ref** укажите `main`.
5. Поле **Выборочные пути** оставьте пустым и нажмите **Добавить маркетплейс**.
6. Найдите плагин **101**, включите его и нажмите **Подключить**.
7. Пройдите авторизацию в 101 через OAuth и вернитесь в Codex.

После подключения Codex должен показать плагин **101** версии `2.0.2` и подключённое приложение 101 MCP.

### 2. Подключение в ChatGPT

Для ручного подключения 101 MCP в ChatGPT сначала обязательно включите **режим разработчика**. Без него кнопка **«+»** для добавления собственного MCP-приложения не появится.

1. Откройте **Настройки → Приложения → Дополнительные настройки**.
2. Включите **Режим разработчика**.
3. Вернитесь в раздел **Приложения** и нажмите **«+»** или **Создать**.
4. Укажите адрес production MCP:

   ```text
   https://app.101-group.ru/mcp
   ```

5. В поле **Название приложения** укажите `101`.
6. [Скачайте логотип 101 в формате PNG](https://raw.githubusercontent.com/101-group/101-ai-plugin/main/plugins/101/assets/MCP_logo.png) и загрузите его как иконку приложения. Так 101 будет проще находить среди подключённых приложений в чате.
7. Запустите сканирование инструментов и пройдите авторизацию через OAuth.
8. Сохраните и включите приложение **101**.
9. [Скачайте архив навыков 101](https://github.com/101-group/101-ai-plugin/raw/refs/heads/main/downloads/101-skills.zip), загрузите ZIP-файл в чат и напишите: **«Установи навыки из этого архива»**. ChatGPT сам разберёт структуру и установит доступные навыки.

После подключения ChatGPT получает инструменты и интерактивные виджеты через 101 MCP, а навыки задают готовые рабочие сценарии. Доступность режима разработчика, пользовательских MCP-приложений и загрузки навыков зависит от тарифа, роли и настроек рабочего пространства ChatGPT.

## Как устроен плагин

Плагин состоит из двух частей:

1. **Навыки 101** — инструкции и рабочие процессы для AI-ассистента.
2. **101 MCP** — удалённое приложение, которое предоставляет инструменты, данные и интерактивные виджеты.

Данные компании не хранятся в этом репозитории. Пользователь подключает собственную учётную запись 101 через OAuth, после чего сервер проверяет его права перед выполнением операций.

## Совместимость с Claude

Текущий пакет использует формат маркетплейса Codex и манифест `.codex-plugin`. Этот Git-репозиторий можно использовать как общий источник для разных AI-агентов, но Claude требуется собственный поддерживаемый манифест и отдельный способ установки. Не считайте текущий пакет напрямую совместимым с Claude, пока соответствующий слой совместимости не будет добавлен и протестирован.

## Безопасность

Репозиторий не содержит паролей, токенов, API-ключей, приватных ключей или пользовательских сессий. Авторизация и права доступа к данным проверяются удалённым сервером 101 MCP через OAuth. Никогда не добавляйте в репозиторий секреты или локальные данные авторизации.
